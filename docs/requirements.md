## Уточнения к примерам пособия

- Предметная область — исходный сайт CD PROJEKT RED из AIP_lectures/task. В каталоге шесть игр, маршруты /games/:gameId, модели CDPRGame и CDPRPlayer, база cdpr_worlds_2026.
- В 8.4 удалён тестовый обработчик /games, но сохранён необходимый маршрутизатор /games/:gameId.
- findById в 10.5 возвращает один документ, поэтому обращение как к массиву из примера исправлено.
- В 10.2 вместо Math.random и HMAC-SHA1 используются встроенные crypto.randomBytes, scryptSync и timingSafeEqual. Смысл упражнения — виртуальный пароль, соль, хеш и проверка — сохранён.
- В 10.3 пароль не печатается; успешный приём формы подтверждается ответом сервера. Ошибочные POST-запросы тоже завершаются ответом.
- В 9.1 resave:false не перезаписывает неизменённые сессии. Счётчик 9.4 меняет сессию на каждом запросе страницы, продлевая минуту активности.
- POST-выход ждёт завершения удаления сессии, затем делает redirect. При входе SID регенерируется.
- Bootstrap 5.3.3 хранится локально в public/vendor/bootstrap вместе с лицензией. Это устраняет зависимость проверки от CDN и ошибочной integrity-строки прежней версии.

## Проверки итоговой версии

14 тестов npm test: модель, сохранение и уникальность, повторный посев, хеширование, форма и неверные данные, регистрация и вход, все шесть защищённых страниц, меню из базы, cookie и счётчик, истечение сессии, выход, удалённый профиль, сохранение входа в новом процессе. Тесты создают собственные временные базы cdpr_guide_test_<случайный id> и удаляют только их.

Проверка Edge: главная и форма при ширине 320, 390, 520, 768, 834, 1000, 1024, 1280, 1440, 1920 px; фильтры, шесть окон игр, четыре окна галереи, изображения, мобильное меню, регистрация, страницы игр, выход и сообщение ошибки. Отдельно выждана настоящая 61 секунда: браузер получил новую сессию, счётчик стал 1. Горизонтального переполнения и ошибок JavaScript не обнаружено. Отчёт: verification/browser.json.

Ветки 4.2–7.3 дополнительно исправлены без переписывания истории: маршруты всех игр, Bootstrap, навигация, точное имя коллекции и демонстрационные скрипты. Внешние изменения README в ранних ветках сохранены.

## Ограничение зависимости из пособия

Требуемый в 4.4 пакет ejs-locals 1.0.2 использует EJS 0.8.8. npm audit отмечает две критические записи для этой цепочки, исправления у пакета нет. Остальные найденные исправляемые зависимости обновлены. Для совпадения с заданием пакет сохранён; сервер по умолчанию слушает только 127.0.0.1. В публичном приложении следует заменить ejs-locals современным layout-движком.
