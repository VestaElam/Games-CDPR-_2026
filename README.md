# Games(CDPR)_2026 — ELECTRIC XTRA

Учебный проект по разделам 3–4 пособия. Тема и оформление перенесены из
[AIP_lectures](https://github.com/VestaElam/AIP_lectures): цифровые технологии,
скорость, безопасность и глобальная сеть. Использован шаблон
[TemplateMo 596 Electric Xtra](https://templatemo.com/tm-596-electric-xtra),
сохранено указание автора дизайна.

## Запуск

```powershell
npm install
npm start
```

Открыть http://localhost:3000/. Для другого порта в PowerShell:

```powershell
$env:PORT = '3100'
npm start
```

## Раздел 3 — MongoDB

MongoDB должна работать на `mongodb://127.0.0.1:27017`. Выполнить из корня проекта:

```powershell
mongosh --file mongodb/3_1_seed.js
mongosh --file mongodb/3_2_find.js
mongosh --file mongodb/3_3_update.js
mongosh --file mongodb/3_4_corrected.js
```

Если `mongosh` не в PATH:

```powershell
& "$env:LOCALAPPDATA\Programs\mongosh\mongosh.exe" --file mongodb/3_1_seed.js
```

- **3.1:** создание/удаление отдельной демонстрационной базы; посев 12 единорогов
  в `learn.unicorns`. Существующая непустая коллекция не перезаписывается.
- **3.2:** 10 упражнений FIND. В №9 использовано условие «виноград или морковка»;
  в решении пособия ошибочно указан `lemon`.
- **3.3:** UPDATE с `$inc`, `$push`, `$set`, `$pull`, `$mul`.
  После упражнений Aurora весит 900, Roodles — 565, у Pilot — 56 вампиров,
  Dunx больше не любит виноград. Повторный запуск изменений пропускается.
- **3.4:** 11 исправленных запросов. Они выполняются на копии
  `learn.unicorns_syntax`, сохраняя результат 3.3. Запускать один раз;
  относительные изменения повторного запуска складываются.

Фактический вывод установленного `mongosh` сохранён в `mongodb/results.txt`.
Аналоги старых команд `insert`, `update`, `count` заменены на современные
`insertMany`, `updateOne`, `countDocuments`.

## Ветки раздела 4

| Пункт | Ветка | Результат |
| --- | --- | --- |
| 4.1 | `main` | Стартовый Express-проект с EJS, главная страница ELECTRIC XTRA и `.gitignore` |
| 4.2 | `4_2` | Три отдельных маршрута: скорость, безопасность, глобальная сеть; статические картинки |
| 4.3 | `4_3` | Общий шаблон `feature.ejs` с параметрами `title`, `picture`, `desc` |
| 4.4 | `4_4` | Подключение `ejs-locals`, общий `views/layout/page.ejs`, обработка 404 с `title` |

Ветки создаются последовательно: `main` → `4_2` → `4_3` → `4_4`.
Переключение: `git switch 4_4`; установка зависимостей после переключения: `npm ci`.
Главная страница сохраняет исходный дизайн ELECTRIC XTRA.
Форма контактов является демонстрацией исходного шаблона.

В 4.4 `ejs-locals` подключён в соответствии с пособием. Этот старый пакет
использует EJS 0.8.8: `npm audit` сообщает о двух критических уязвимостях.
Версия сохранена для учебного локального проекта; для реального развёртывания
потребуется заменить этот движок современным вариантом layout.

Исходный пример раздела 2 с POST-формой сохранён в `examples/section-2/`.
Подключение MongoDB к Express-приложению относится к разделу 6 пособия;
в разделах 3–4 упражнения базы выполняются отдельно через `mongosh`.
