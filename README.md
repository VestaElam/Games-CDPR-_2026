# Games(CDPR)_2026 — Миры CD PROJEKT RED

Учебный проект по разделам 3–4 пособия. Основа — именно сайт из
[AIP_lectures, ветка task](https://github.com/VestaElam/AIP_lectures/tree/task),
исходный коммит `89ba51552ebf9aa4200f0b494d0c2288dffe4883`.
Сохранены русские тексты, оформление, 12 изображений, шесть карточек игр,
фильтры вселенных, модальные окна, галерея, FAQ и мобильное меню.
Автор дизайна [Electric Xtra / TemplateMo](https://templatemo.com/tm-596-electric-xtra)
указан в подвале исходного сайта.

## Запуск

```powershell
npm ci
npm start
```

Открыть http://localhost:3000/. Для другого порта: `$env:PORT = '3100'`.
GitHub преобразовал запрошенное имя `Games(CDPR)_2026` в `Games-CDPR-_2026`.

## Раздел 3 — MongoDB

MongoDB должна работать на `mongodb://127.0.0.1:27017`. Выполнить из корня проекта:

```powershell
mongosh --file mongodb/3_1_seed.js
mongosh --file mongodb/3_2_find.js
mongosh --file mongodb/3_3_update.js
mongosh --file mongodb/3_4_corrected.js
```

Если `mongosh` не в PATH:

```powershell
& "$env:LOCALAPPDATA\Programs\mongosh\mongosh.exe" --file mongodb/3_1_seed.js
```

- **3.1:** создание/удаление отдельной демонстрационной базы; посев 12 единорогов
  в `learn.unicorns`. Существующая непустая коллекция не перезаписывается.
- **3.2:** 10 упражнений FIND. В №9 использовано условие «виноград или морковка»;
  в решении пособия ошибочно указан `lemon`.
- **3.3:** UPDATE с `$inc`, `$push`, `$set`, `$pull`, `$mul`.
  После упражнений Aurora весит 900, Roodles — 565, у Pilot — 56 вампиров,
  Dunx больше не любит виноград. Повторный запуск изменений пропускается.
- **3.4:** 11 исправленных запросов. Они выполняются на копии
  `learn.unicorns_syntax`, сохраняя результат 3.3. Запускать один раз;
  относительные изменения повторного запуска складываются.

Фактический вывод установленного `mongosh` сохранён в `mongodb/results.txt`.
Аналоги старых команд `insert`, `update`, `count` заменены на современные
`insertMany`, `updateOne`, `countDocuments`.

## Ветки раздела 4

| Пункт | Ветка | Результат |
| --- | --- | --- |
| 4.1 | `main` | Express/EJS, главная страница исходного CDPR-сайта, статика и .gitignore |
| 4.2 | `4_2` | Три маршрута с res.send: /cyberpunk, /witcher3, /gwent; картинки в public/images |
| 4.3 | `4_3` | Шаблон game.ejs с title, picture, desc; переход из описания на страницу игры |
| 4.4 | `4_4` | ejs-locals, общий views/layout/page.ejs для главной, игры и ошибки; title у 404 |

Текущий этап этой ветки: **4.3**. Каждый этап опубликован отдельным push.
Ветки содержат последовательные состояния задания. Для итоговой версии:
`git switch 4_4`, затем `npm ci`.

На этапах 4.3–4.4 в окнах Cyberpunk 2077, Ведьмака 3 и ГВИНТА доступна
ссылка на отдельную страницу. Остальные карточки сохраняют исходные описания.
Изображения, логотип и названия принадлежат их правообладателям.

Исходный пример раздела 2 с POST-формой сохранён в examples/section-2/.
Подключение базы к Express относится к разделу 6; упражнения раздела 3
выполняются отдельно через mongosh.
